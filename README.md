# 월담 — 다차원 동질성 지표 웹사이트

정적 HTML 사이트로, 월담 프로젝트 설명과 대전광역시 다차원 동질성 지표를 보여줍니다.

## 구성

- **프로젝트 · 지표 설명**
  - 소개 이미지 자리(비움)
  - 학교별 동질성 지표 순위 (Hₘ 오름차순)
  - 지표별 순위 (선택한 지표 오름차순)
- **다차원 동질성 지표**
  - 대전광역시: 학교별 지표 테이블 + 지표 해설
  - 대구광역시: 자리만 비워 둠

## 실행

로컬에서 정적 서버로 열면 됩니다 (`fetch`로 JSON을 불러옵니다).

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.
